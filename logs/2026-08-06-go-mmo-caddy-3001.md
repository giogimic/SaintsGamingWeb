## Goal

Wire the Go MMO parallel test stack onto **port 3001** when using an
**existing Caddy install**, and avoid Docker name collisions by appending
`1`, `2`, `3`, … to container / compose project names when the base name is
already in use.

| Area | Detail |
|------|--------|
| Default port | `3100` → **`3001`** (`config.Load`, `.env.example`, setup, README) |

| Names | `saints-gaming-go-mmo` → `…1` / `…2` / `…3` if `docker ps -a` shows the name |
