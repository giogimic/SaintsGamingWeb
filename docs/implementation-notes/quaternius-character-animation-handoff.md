## Implementation update — 2026-10-03

This section supersedes the earlier working draft and initial “no source changes” verification text below. The earlier audit findings describe the pre-change state; the resolved behavior is listed here.

### Implemented

- **Base body / clothing overlap:** Kept the original complete source meshes as `public/models/quaternius/quaternius_base_{male,female}_fullbody.glb` and prepared the canonical base files into skinned `QuaterniusBody_Head`, `Torso`, `Arms`, `Legs`, and `Feet` meshes. The preprocessing uses each triangle's four skin influences to assign a body region, carries all source vertex attributes and skin weights into the new meshes, preserves the 65-joint skin, and retains the separate face/eye/eyebrow meshes. Outfit coverage now hides only the appropriate regions; it no longer removes the whole actor or its head. The repeatable command is `npx tsx scripts/prepare-quaternius-base-regions.ts`.
- **Wardrobe catalog:** The checked-in manifest now exposes all 20 locally supplied modular parts with Quaternius pack, 65-bone skeleton, sex/body matching, creator visibility, categories, hide rules, and available color maps. The archive also supplies four assembled `.gltf` outfit exports. The seed and ingest scripts convert and import those as one-piece clothing options; they are not duplicated as 30–40 MB local GLBs because the same clothing geometry is already available as individual modular parts and the assembled files embed large copies of the same texture maps. The assembled pieces hide conflicting clothing/arms/legs/shoes while leaving the base head and optional headwear available.
- **Head/hair and color variants:** Registered the eight local base-character hair/face assets, made the Ranger hood creator-visible, and corrected hood hair suppression for preview and runtime attachment ordering. Added selectable Peasant color variation 2 and Ranger color variation 3, the only alternate outfit base-color maps present in the supplied archive. External maps are applied to cloned preview materials and at Babylon attachment load without losing asset transforms or shared base materials.
- **Animation libraries:** Registered regular and root-motion profiles for UAL1 and UAL2. Each of the four supplied GLBs contains 43 named animation groups and a measured 65-bone Quaternius rig. Clip catalogs, categorization, rig signatures, root-motion flags, and compatible profile IDs are written into the manifest and seed metadata. Profile slots use names verified in the embedded bank, and the chosen clip name is passed to both Babylon and client rendering. A missing group now fails safely instead of silently playing group zero.
- **Uploaded rigs:** Animation-bank uploads get the `ANIMATION` type. Studio profile and clip choices use recorded bank skeletons and only expose Quaternius profiles to measured humanoid bipeds with a 70% Quaternius bone-name match plus required pelvis/spine/head/limb bones. Existing/new uploaded humanoid-compatible rigs can use the UAL profiles; rig family alone does not qualify a quadruped or flyer.
- **Monsters/creatures:** Fixed model selection to preserve stable asset ID, URL, scale, rig analysis, and animation metadata. Creature/monster pickers query creature assets; unknown explicit models no longer fall through to Brute identity. The live test-spawn path sends the configured world model. The supplied Imp and Puglin are each measured at 55 bones, classified as humanoid bipeds, have no embedded clips, and pass the UAL1/UAL2 profile compatibility threshold. These asset-specific facts are generated by the repeatable catalog sync.
- **Source-path and import correctness:** Import/seed paths now resolve `characters`, `items`, and `monsters` under the supplied `sg anims` root (or `QUATERNIUS_SOURCE_DIR`), fail clearly when a required pack folder is absent, inspect animation/rig metadata, and cover the four UAL files, assembled outfits, modular parts, hairstyles, supplied Bestiary GLBs, and RPG models/icons. `scripts/sync-quaternius-manifest.ts` regenerated the canonical catalog.
