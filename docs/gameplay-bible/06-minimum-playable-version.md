# Saints Gaming — Gameplay Bible: Minimum Playable Version (MPV)

## Draft v0.2

# MPV Identity

## The First Playable Saints Gaming Experience

The Minimum Playable Version is not a demo, nor is it a small original proof-of-concept.

It is the smallest version of Saints Gaming that proves the complete vision: **A multiplayer creature RPG engine and platform where players can explore, battle, collect, build, socialize, and create.**

The MPV should prove the core systems work together by actively running a complete Tuxemon-based area inside the Saints engine.

---

# MPV Goal

A player should be able to:

1. Enter the multiplayer lobby.
2. Meet other players.
3. Explore a playable Tuxemon-based area.
4. Encounter creatures.
5. Battle using the MMO combat system.
6. Capture creatures and manage inventory.
7. Improve their character through skills.
8. Build a personal space using the base system foundation.
9. Interact with basic editor functionality.

If this works, the engine's foundation is proven.

---

# Core Player Journey

## Step 1 — Spawn in the Lobby

The player enters the central hub. Available immediately:
✓ Character movement
✓ Multiplayer visibility
✓ Chat
✓ Player list
✓ Basic UI
✓ Inventory access

The player understands: "This is a living online world."

---

# Step 2 — Choose an Activity

The lobby provides paths:
* **Explore**: Travel to the Tuxemon-based adventure zone.
* **Train**: Practice combat.
* **Build**: Access personal base.
* **Socialize**: Interact with players.

---

# Step 3 — First Adventure Zone

The first world map is a playable Tuxemon area. It contains grass, trees, NPCs, encounters, and roaming monsters. 

The map exists to prove: World loading, collision, multiplayer sync, encounters, and interaction.

---

# Step 4 — Creature System

The first version includes:
* **Capture**: Encounter and catch creatures.
* **Storage**: Manage the collection.
* **Basic Progression**: Level, stats, abilities, and evolution mechanics.

(Fusion and breeding come after the foundation works).

---

# Step 5 — Combat System

## MPV Combat Choice
Real-time MMO combat. Required: Target selection, basic attack, ability hotbar, cooldowns, health system, creature abilities, and enemy AI.

## Multiplayer Combat
Support 1 player initially, proving "Players can fight together" before expanding to full parties.

---

# Step 6 — Skills

The MPV includes the RuneScape-inspired skill framework.
Initial skills: Combat (Attack, Defense, Mastery), Gathering (Woodcutting, Mining), Crafting (Basic crafting).

---

# Step 7 — Base System

The first base system proves the foundation.
Players receive a small plot, object inventory, and save/load system.
Players can place, move, and remove objects, save their layout, and visit another player's base.

---

# Step 8 — Editor Foundation

The editor begins as a developer tool to build the MPV.
Required: Load maps, create maps, place objects, edit collision, add spawn points.
Import System: Support for existing Tuxemon assets and legacy maps.

---

# Development Priority Order

## Phase 1: Engine Foundation
1. Stable world loading (Babylon.js framework)
2. Player movement and multiplayer sync
3. Lobby and base system foundation
4. Inventory and Skills architecture

## Phase 2: Tuxemon Compatibility Layer
5. Tuxemon map parsing and legacy support
6. Creature encounters, capture, and evolution logic
7. Turn-based-inspired real-time MMO combat mechanics
8. NPCs, dialogue, and story progression integration

## Phase 3: MMO Feature Expansion
9. Deep party combat and hotbars
10. Extended player bases and housing
11. Advanced social trading and guilds
12. Deepened skill and crafting systems

## Phase 4: Original Saints Worlds
13. Creator tools expansion
14. Community-built districts and custom adventure zones
15. Publishing and sharing entirely new user-generated worlds

# Required MPV Content

## Maps
Minimum:
* **Lobby**: Social hub and testing area.
* **Tuxemon-Based Wild Zone**: Exploration and encounters.
* **Player Base Zone**: Building and visiting.

## Required Creatures
10-20 creatures to prove the systems (common, rare, evolution examples, different combat roles).

## Required Objects
Environment (trees, rocks, water), Buildings (house, storage, crafting station), Decoration (furniture, signs), Interactive (chest, door, teleporter).

## UI Requirements
HUD (Health, Hotbar, Party, Chat) and Panels (Inventory, Skills, Creature collection, Settings) with basic customization.

## Multiplayer Requirements
Players must be able to see each other, move together, chat, party, enter the same map, fight, and visit bases.

---

# MPV Success Test

The MPV succeeds when a player can say:

> "I logged into the engine, explored a Tuxemon area with friends, caught a creature, fought using MMO abilities, leveled up my skills, and built my own place."

That proves Saints Gaming. Everything beyond this expands the world, but this establishes the platform.
