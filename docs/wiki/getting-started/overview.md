# Platform & Game Overview

Welcome to **Saints Gaming** ([SaintsGaming.net](https://SaintsGaming.net)), a unified web community platform and embedded 2.5D sandbox MMO powered by Next.js 15, React 19, Babylon.js WebGL, Socket.io, and a dedicated Go `:3001` realtime socket backend.

---

## 🎯 Core Game Pillars

Every system in Saints Gaming adheres to three foundational tenets:

1. **Does this make the world feel more alive?**
   - Autonomous NPC wander patterns, day/night cycles, responsive soundscapes, and wild creature habitats.
2. **Does this make the world more social?**
   - Shared multiplayer zones, player trading, group dungeon raids, highscore leaderboards, and community forum integration.
3. **Does this make the world more creative?**
   - Complete in-browser world authoring toolset (`/studio`), custom character archetypes, custom quest authoring, and modular 2.5D sprite compositing.

## 🕹️ Game Terminology Standard

To maintain clarity across all documentation and engine subsystems, Saints Gaming uses canonical terms:

| Canonical Term | Former / Legacy Term | Description |
| :--- | :--- | :--- |
| **Saint** | *Tamer / Player* | The canonical operative identity of player characters in the MMO world. |
| **Saints Buddy Battles** | *Creature Battles* | Companion creature collection encounters focusing on weakening and capturing. |
| **Hero Battles** | *PvE Monster Battles* | Real-time MMO combat against monsters focused on defeat and item drops. |
| **Player Battles** | *PvP / Arena* | Direct competitive player-versus-player duels and arena encounters. |
| **World Studio** | *World Builder* | The live in-engine map authoring and script creation suite (`/studio`). |
