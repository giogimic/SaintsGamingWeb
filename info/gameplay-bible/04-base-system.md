# Saints Gaming — Gameplay Bible: Base System (Draft v0.1)

# Base System Identity

## Your Base is Your Personal World

The base system is not simply player housing.

It is the player's permanent piece of the world.

A base represents:

* Progression
* Creativity
* Production
* Identity
* Social expression

The player does not just own a room.

They build a place that grows with them.

---

# Base System Purpose

The base connects multiple gameplay systems:

* Gathering
* Crafting
* Creature management
* Economy
* Social interaction
* World creation

The player loop becomes:

**Explore → Gather → Build → Improve → Create → Share**

---

# Base Ownership

Every player can have a personal territory.

A base exists inside a dedicated world system.

Example:

```
World Map

 |
 |-- Settlement Field
        |
        |-- Player Base A
        |-- Player Base B
        |-- Player Base C
        |-- Guild Area
```

The player travels to the settlement area and enters individual bases.

# Building System

The building system uses object placement, not traditional tile painting.

The goal:

**Simple like Habbo Hotel, powerful like a game editor.**

Players can place:

* Furniture
* Buildings
* Decorations
* Machines
* Farming objects
* Creature structures
* Functional objects

---

# Object System

Every placed object is a real game object.

Example:

A tree is not just an image.

It is:

```
Tree Object

Properties:
- Position
- Rotation
- Collision
- Resource output
- Growth state
- Ownership
- Interaction
```

This allows objects to become gameplay systems.

---

# Creature Integration

Creatures are part of the base.

They are not just stored.

Creatures can:

* Live in habitats
* Assist production
* Defend areas
* Generate resources
* Provide bonuses

Example:

A fire creature:

* Powers furnaces
* Helps smelting

* Helps farming
* Improves plant growth
